# ZoomCart Merchant Product Service

This service manages product information for merchants in the ZoomCart application.

## Purpose

The Merchant Product Service is responsible for handling all aspects of product management for merchants. This includes creating, updating, and deleting product listings, as well as managing inventory levels.

## Key Features

*   **Add New Products:** Merchants can add new products to their catalog, providing details such as name, description, price, and images.
*   **Update Existing Products:** Merchants can modify the information of their existing products.
*   **Manage Inventory:** Merchants can update stock levels for their products.
*   **View Products:** Merchants can view a list of their products and their current status.
*   **Delete Products:** Merchants can remove products from their catalog.

## Technologies Used

*   **Spring Boot:** An open-source Java-based framework used to create microservices.
*   **Java:** The primary programming language for the service.
*   **PostgreSQL:** A powerful, open-source object-relational database system used for data persistence.
*   **Spring Data JPA:** Part of the Spring Data family, makes it easy to implement JPA based repositories.
*   **Spring Web:** Part of the Spring Framework, used for building web applications, including RESTful APIs.
