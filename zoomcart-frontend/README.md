# ZoomCart Frontend Service

This service provides the user interface for the ZoomCart application.

## Key Features

*   **Product Browsing:** Users can browse through a wide variety of products.
*   **Cart Management:** Users can add products to their cart, update quantities, and remove items.
*   **User Authentication:** Users can create accounts, log in, and manage their profiles.
*   **Order Placement:** Users can place orders and track their status.
*   **Merchant Functionality:** Merchants can manage their products and view orders.

## Technologies Used

*   **React:** A JavaScript library for building user interfaces.
*   **Redux:** A predictable state container for JavaScript apps.
*   **React Router:** For handling navigation within the application.
*   **Axios:** For making HTTP requests to the backend API.
