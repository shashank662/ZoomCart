# ZoomCart
ZoomCart is a cutting-edge eCommerce platform specializing in smartphones. Built to provide a smooth and engaging shopping experience, ZoomCart offers an extensive range of smartphones from top brands, allowing customers to find and purchase their ideal devices effortlessly.

## Services

### zoomcart-frontend
The frontend service for the ZoomCart application, providing the user interface for customers and merchants. It handles product browsing, cart management, user authentication, order placement, and merchant product management. Built with React, Redux, React Router, and Axios.

### zoomcart-merchantproduct
Manages product information for merchants in the ZoomCart application. Merchants can add new products, update existing products, and manage inventory. Built with Spring Boot, Java, and PostgreSQL.

### zoomcart-orders-and-cart
Manages customer shopping carts and processes orders. It handles adding items to the cart, placing orders, and allowing users to view their order history. Built with Spring Boot, Java, and MongoDB.

### zoomcart-product
Manages and provides product information to customers. It allows users to browse, search, and view detailed information about products, including categories and reviews. Built with Spring Boot, Java, Elasticsearch, and potentially a primary datastore like PostgreSQL.

### zoomcart-search
Provides comprehensive search functionality for products. It enables keyword search, filtering, sorting, and suggestions/autocomplete to help users find products quickly and effectively. Built with Spring Boot, Java, and Elasticsearch.

### zoomcart-user
Manages user accounts, authentication, and authorization. It handles user registration, login, profile management, password management, and address management. Built with Spring Boot, Java, Spring Security (potentially with OAuth2 and JWT), and PostgreSQL.
